This project is an implementation some of ECDLP solving algorithms.
This project uses BouncyCastle package.
To install the package enter this comand in PowerShell in the project directory: dotnet add package BouncyCastle.Cryptography.
There were realisated next algorithms:
1. BSGS (Baby-Step Giant-Step)
2. Pollard`s Rho
3. Pollard`s Lambda
4. Gaudry-Schost

Unit tests for the implemented algorithms are also included.
